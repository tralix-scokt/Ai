How to deploy the backend
  1. Push this repository to GitHub. The workflow in .github/workflows/deploy-backend.yml deploys server/ for you.
  2. Add three repository secrets: CLOUDFLARE_API_TOKEN, CLOUDFLARE_ACCOUNT_ID and OPENAI_API_KEY.
  3. Run the Deploy TRALIX backend workflow. It prints the worker URL.
  4. Put that URL in backend.json ({"url": "https://…"}) and push — or paste it above to use it on this device only.

Prefer your own server? OPENAI_API_KEY=… node server/node.js --static serves the app and the API together. The key stays on the server either way — this frontend never receives it.
